# Youth Hub Connect

Project Overview: > Build a modern, clean, website for a high school Youth Advisory Board. The goal is to let students quickly view upcoming school events (like Ethnic Fest, workshops, and board meetings) and sign up for smaller activities or volunteer slots.

Design & Aesthetic: > * Style: Vibrant, welcoming, modern, and uncluttered (appealing to high school students).

Color Palette: Warm, inclusive tones (e.g., deep navy secondary, vibrant accent colors like teal or coral, soft light background).

Navigation: A sleek top navigation bar with a logo/title ("Youth Advisory Board"), a search/filter bar, and quick links to "Upcoming Events", "About Us", and "Contact/Links".

Core Pages & Features: >

Hero Section: > * Bold heading welcoming students.

Quick action buttons: "View Events" and "Join a Committee/Sign Up".

A banner for the next major event (e.g., "Ethnic Fest - Coming Soon!").

Event Calendar & Cards Grid: > * Filter buttons at the top: All, Cultural Fests, Volunteering, Workshops, Meetings.

Responsive grid showing event cards. Each card must include:

Event Title, Date, Time, and Location.

A category tag badge (e.g., "Culture", "Volunteering").

A brief description.

An "Add to Calendar" button (supporting Google/Apple Calendar).

A "Sign Up" button that opens an event modal/popup.

Interactive Sign-Up Modal: > * Opens when clicking "Sign Up" on an event card.

Minimal form fields: Full Name, Student Email, Grade Level (dropdown: 9, 10, 11, 12), and Role/Slot Selection (e.g., "Attendee", "Volunteer", "Booth Host").

Instant submit confirmation message upon submission.

Footer: > * Social media icon links (Instagram, TikTok).

Quick links to school resources or feedback form.
