The Youth Advisory Board (YAB) Event Hub is a fast, modern calendar website designed for Creek students. It brings together all upcoming school events, school clubs, volunteer opportunities, and weekly Monday meetings into a single, easy-to-search dashboard.

How It Works:

Dynamic Event Updates: The website connects directly to a live Supabase database. Whenever an organizer adds, updates, or deletes an event in the database, the website updates automatically—no coding or site redeployment required.

Instant Filtering & Search: Students can filter events by category or use the search bar to instantly find activities by keyword, topic, or location.

Lightweight & High-Speed: By focusing purely on event discovery and removing complex user sign-ups, the site loads instantly on mobile devices, tablets, and laptops while consuming virtually zero database storage.

Zero Maintenance Hosting: Hosted on Vercel's global delivery network, ensuring 100% uptime, fast performance, and zero hosting costs for the school.
